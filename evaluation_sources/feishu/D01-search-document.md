# D01 搜索并选择飞书文档（读取 / 同名消歧）

## 1. 背景与目标

用户记得文档关键词，需要定位正确方案。目标是选中真实文档并保留其身份供后续读取。

## 2. 触发条件

已连接飞书；有关键词或所有者线索，尚无唯一文档链接。

## 3. 用户的话

“帮我在飞书找一下《发布方案V2》的文档。”

## 4. Agent 期望链路

1. 调用 search_docs(query, provider=["feishu"])，按当前 ToolHub Schema 处理 results[].docs[] 和分页字段。
2. 多个候选交用户选择；唯一命中直接读取；成功空结果说明未找到，权限失败说明真实原因。
3. owner 缺失时可调用 feishu_get_user_profile 补充资料。

## 5. UI 期望响应链路

搜索结果 list_simple；读取选中文档正文 markdown_title_body；过程状态使用 tool_start；真实调用失败才使用 tool_fail。

## 6. 验收关注点

- 同名未选定前不修改文档。
- 缺失 owner 姓名不以内部 ID 充当人名。
- 分页未结束不声称搜遍全部。
- 未知结果先回查。
